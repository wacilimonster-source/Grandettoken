# 三形态展示体检与修复设计（2026-10-22）

> 范围：面板（panel）/ 紧凑条（compact）/ 胶囊（pill）在**各种数据与设置下**的展示。
> 方法：真机窗口 + CDP 注入合成数据，逐场景截图并量化越界（`build/visual-forms.js`）。
> 结论：13 个问题，其中 4 个是"整块内容被裁掉"级别的（P0）。先出设计，再动代码。

---

## 1. 三形态的契约（这次体检的判据）

三种形态不是"同一份 DOM 换个宽度"，各有各的**信息上限**与**允许的裁切**。
下面这张表是本次所有判定的依据；表中没写的，一律按"不许越界"处理。

| | 面板 panel | 紧凑条 compact | 胶囊 pill |
|---|---|---|---|
| 窗口（标准字号） | 400×580 | 380×46（宽随内容贴合，最大 380） | 200×46（宽随内容） |
| 一屏放什么 | 风险带 + 分组列表（可滚） | 一行 chip（横向滚动关闭） | 一个渠道：图标 + 数字 + 限定语 |
| 允许纵向滚动 | ✅ 列表内 | ❌ | ❌ |
| 允许横向滚动 | ❌ | ❌（超出即裁，必须靠降级） | ❌ |
| 允许省略号 | ✅ 名称、副行 | ✅ 名称 | ❌（数字不许截断） |
| 允许出现分组标题 | ✅ | ❌ | ❌ |
| 允许出现第二行（`.r2`） | ✅（仅紧急行） | ❌ | ❌ |
| 允许出现签到徽标 | ✅ | ✅（一个常驻 chip） | ❌ |
| 空数据时 | 空态卡（去恢复 / 去配置） | 一条最短 chip | 主数字 `——` |

**一条总原则**（这次 4 个 P0 里有 3 个违反它）：**折叠形态没有滚动条，任何"多出来的内容"都必须靠降级消失，不能靠裁切消失。**

## 2. 测试方法

新增 `build/visual-forms.js`：连真机 CDP，把合成数据注入页面 → 逐形态 `applyForm` →
截图 + 量三样东西：

- **横向越界**：元素右边界超出窗口（排除被祖先 `overflow:hidden` 有意裁掉的）
- **纵向越界**：元素下边界超出卡片（面板列表自己滚，不计）
- **文本裁切**：`scrollWidth > clientWidth` 的叶子节点（省略号算正常，记下来看是不是裁过头）

场景 16 个 × 3 形态 = 48 张图，产物在 `docs/assets/qa-forms/`：

## 3. 问题清单

### P0-1 吸附竖条漏进面板形态（已修）

- **现象**：面板只剩标题栏 + 风险带 + 底栏，中间一大片空白，渠道一行都看不见。
- **根因**：v0.1.56 新增的 `.dock-body{display:flex!important}` 没有挂在 `body.docked` 下，
  盖掉了前面的 `.dock-body{display:none}`；它 `height:100%`，在 flex 列里抢走 415px，
  `flex:1` 的列表被压成 0 高。
- **修复**：`body.docked .dock-body{display:flex;…}`（去掉 `!important`，靠状态门提高优先级）。
- **验收**：面板形态 `.dock-body` 计算值 `display:none`；吸附态 `flex/column`、占满窗口。
- **防复发**：新增 `build/check-css-forms.js`（纯文本检查，零依赖）：凡是"基础规则是
  `display:none` 的整块容器"，其它规则再给它 display 时必须带 `body.<状态>` 前缀。已接进 CI。

### P0-2 紧凑条里出现竖排的「需要处理 1」

- **现象**：紧凑条左侧多出一个竖着写的分组标题，把 chip 挤到右边。
- **根因**：v0.1.56 的分组标题 `.grp` / 失败横幅 `.fstrip` / 骨架 `.sk-wrap` 都是**面板的纵向结构**，
  紧凑条（`flex-direction:row`）里它们变成一个被压扁的块。
- **修复**：`body.form-compact .grp, .fstrip, .sk-wrap {display:none}`。

### P0-3 紧凑条的第二行被裁（`.r2`）

- **现象**：有紧急行时，chip 下面多出「5 小时窗 · 2.0 小时 后恢复 · 周期 62%」，
  半截露在卡片外面（实测列表高 74px，卡片只有 46px，**超出 18px**）。
- **根因**：`.row.urg .r2{display:block}` 是面板"两级行"的规则，没在紧凑条里关掉。
- **连带影响**：chip 被撑宽 → 同样宽度下能放的渠道从 3~4 个掉到 1 个（13 渠道只剩 1 个 + `+12`）。
- **修复**：`body.form-compact .r2{display:none}`。紧急与否已经由 chip 上的 `限流/低于底线` 标签表达。

### P0-4 紧凑条空态文案换行被裁

- **现象**：冷启动/全隐藏时，chip 里「正在取数 · 首次启动需要几秒」折成两行，下半截被裁。
- **根因**：`.cempty` 的文本直接取自底栏状态，长度不受控；且没有 `nowrap/ellipsis`。
- **修复**：空态文案单独给短句（取数中→「取数中…」，全隐藏→「渠道已全部隐藏」），
  并给 `.cempty` 补 `max-width/overflow:hidden/text-overflow:ellipsis/white-space:nowrap`。

### P1-1 紧凑条横向裁切（大数字 / 多渠道）

- **证据**：`many` 场景 `scrollWidth 283 > clientWidth 279`；`big` 场景 `340 > 321`（裁掉 19px）。
- **根因**：`fitCompact` 用固定 `moreW = 28u` 预留 `+N` 的宽度，而实际 `+12` 更宽；
  另外它按 `offsetWidth` 预算，**没有在落位后复核**，四舍五入与边框会吃掉几像素。
- **修复**：① `+N` 的宽度改成**真量一次**（先插进去量 `offsetWidth`，再决定收几个）；
  ② 落位后复核 `list.scrollWidth > list.clientWidth`，超出就从末尾再收一个 chip，直到不超。

### P1-2 没有金额合计时，风险带整条消失

- **证据**：`checkin`（纯积分渠道）、`loading`、`empty` 三个场景里，风险带整条不见，
  列表/骨架直接顶到标题栏下 —— 数据回来时**整页向下跳 73px**。
- **根因**：`renderRiskBand` 在 `totals` 里没有人民币合计时直接 `display:none`。
- **期望**：风险带是面板的固定结构（三格：总余额 / 最紧 / 签到），**永远在**；
  没有数字时第一格写 `——`，副行留空。这跟 D02「全空 = ——，与'确定是 0'分开写」是同一条。
- **修复**：去掉整条隐藏的分支；`cny` 为空时渲染 `——`（`title` 说明"还没有人民币渠道"）。

### P1-3 底栏计数双算

- **证据**：8 个渠道（其中 3 个预警）显示「8 正常 · 3 预警」，加起来 11 > 8。
- **根因**：`withKey.length - bad` 没有减掉 `warn`。
- **修复**：`正常 = withKey.length - bad - warn`；三段都为 0 时不显示。

### P1-4 鉴权/失败行仍然显示旧数值,没有"上次"的标记

- **证据**：`auth` 场景里 Claude 行写着「取数失败 · 需登录 · 失联」,右边却还是 `62.0%`。
- **根因**：失联时 `c.remaining` 是**最近一次成功取到的数**（`renderRow` 一直直接用
  `c.remaining`），而 `.rhint`「显示的是 X 的成功快照」只在 `stale` 态才画。
- **期望**：数字可以留（用户要的就是"大概还剩多少"），但必须**有出处**。
- **修复**：`isOld = isStale || failed` —— 失联行也画 `.rhint`。
  （原设计想过写成 `——`，会砍掉用户真正想看的数，且展开区本来就有详情，不做。）

### P1-5 骨架期底栏状态不更新

- **证据**：`loading` 场景底栏还是上一轮的「8 正常 · 3 预警」。
- **根因**：骨架分支在算底栏之前 return。
- **修复**：骨架路径也更新 `fdot/fstat`（`未配置渠道` / `正在取数…`）。

### P2-1 风险带副行裁得偏狠（**接受，不改**）

`div.sb` 在 102px 的格子里塞「限流 · 5 小时窗 · 2.0 小时 后恢复 · 周期 62%」（191px），
省略号切在第二个词。**接受的理由**：同一句话在紧急行的 `.r2` 里完整显示（就在下面一行），
风险带只需要回答"谁最紧"，不需要在那儿把恢复时间说完；强行缩短会把 "5 小时窗" 也砍掉。

### P2-5 紧急行的第二行与数值副行重复

- **证据**：WorkBuddy 行下面出现两次「无近期到期」（`.r2` 回退到 `subVal`，而 `.p` 也是它）。
- **修复**：`.r2` 只在 `hv.secondary` 存在时才有内容；`.row.urg .r2:empty{display:none}` 不再占行。

### P2-6 「最紧」格把数字裁掉了

- **证据**：`WorkBuddy 1…` —— 102px 的格子放不下「名字 + 数字」，被省略号吃掉的是**数字**。
- **修复**：名字单独包 `<span class="rn">`，让它缩（带省略号），数字不缩。
  代价是名字只剩 5~6 个字（`Claud… 0.0%`），**接受**：这一格要回答的是"谁最紧、还剩多少"，
  全名在下面那一行与 tooltip 里都有。

### P2-2 全隐藏时仍显示「✓ 0/0」

签到 chip（紧凑条）与签到格（风险带）在 `total === 0` 时都改成 `——` / 不渲染。

### P2-3 失败横幅会随列表滚走

`.fstrip` 在 `#list` 内部，滚到下面横幅就没了。改为 `position:sticky;top:0`（不改 DOM）。

### P2-4 紧凑条降级偏保守（4 渠道只显示 1 个 + `+3`）

**不是缺陷**：实测 8 渠道下 380px 最多放 2 个 chip（chips 94/110px + 签到 chip 48 + 按钮组 58
+ 留白 15 = 123px chrome），2 个 chip + `+6` 是算术上限，与设计「紧凑条的信息上限：两个数」一致。
保留观察：若 chip 因文案普遍变宽导致只能放 1 个，再议。

## 4. 修复设计（按文件）

### `app/src/styles.css`

```css
/* 折叠形态没有滚动条:面板的纵向结构一律不许进来 */
body.form-compact .grp,
body.form-compact .fstrip,
body.form-compact .sk-wrap,
body.form-compact .r2 { display: none }

/* 空态 chip:一句话、一行、超出省略 */
.cempty{ max-width:calc(300px*var(--u)); overflow:hidden; text-overflow:ellipsis; white-space:nowrap }

/* 失败横幅:滚列表时钉在顶部 */
.fstrip{ position:sticky; top:0; z-index:3 }
```

### `app/src/app.js`

1. `fitCompact`：
   - `+N` 的宽度改成**真量**（插一个 `+99` 的隐形 `.more` 量 `offsetWidth`）；
   - 间隙数改成 `n - 1 + (hidden ? 1 : 0)` —— 以前有 `+N` 时少算最后一个 chip 与徽标之间的
     一个 gap（10px），末尾 chip 被裁 4~10px（实测 many 283 > 279）。
2. `renderRiskBand`：删掉 `display:none` 分支，`cny == null` 时渲染 `——`。
3. 底栏计数：`正常 = withKey.length - bad - warn`。
4. `renderRow`：失联行也画 `.rhint`（"显示的是 X 的成功快照"）。
5. 骨架分支：更新底栏状态。
6. `compactCheckinChip`：`total === 0` 不渲染。

### 不做的事（明确边界）

- 不给紧凑条加横向滚动（设计上就是"降级到放得下"）。
- 不改三形态的窗口尺寸公式（46/560 是设计值）。
- 不在胶囊里加签到徽标（信息上限：图标 + 数字 + 一个限定语）。
- 不动 `fontScale` 的换算（xl 下三形态的尺寸是对的，只是内容要跟着规则走）。

## 5. 验收

**自动化**

- `build/visual-forms.js` 全场景：紧凑条 `#list` 不再纵向越界；`scrollWidth ≤ clientWidth`；
  面板无横向越界；风险带在 loading/empty/checkin 三个场景都在。
- `build/check-css-forms.js` 通过（形态门守卫）。
- `cargo test`（core）全绿。

**人工（真机）**

1. 面板：9 渠道滚动、展开一行、切到紧凑条再切回。
2. 紧凑条：紧急行（限流）不再有第二行；13 渠道时 `+N` 与 chip 都不被裁。
3. 胶囊：大数字不被截断；限流时带「限流」限定语。
4. 特大字号下重复 1~3。
