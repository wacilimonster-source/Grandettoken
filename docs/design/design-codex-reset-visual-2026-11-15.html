8 项视觉精修逐点对照 点击左侧画布可直接交互

1. 详情内嵌入口卡片化.cr-entry + .cr-compact-cards

现状常态无背景无内边距，悬停才突兀亮起贴边色块。优化后对齐 V2 .expiry-summary（带状态微着色描边，右上角内联 查看建议 ›），重置卡独立成带圆角边框的 .expiry-table 风格列表，「比订阅晚」改为胶囊小标签。

2. 消除双标题栏打架.cr-page-head

外层 #detailHead 已固定显示 Codex 图标与关闭按钮，现状内部又画一道粗底线 + 双行大标题。优化后收敛为 32px 单行面包屑导航条（左 ‹ 返回 Codex 胶囊按钮 + 右静态口径说明），首屏省出 22px。

3. 结论横幅全宽化.cr-verdict-card

现状左列放 68px 宽方块徽标导致左下角留空、右列文字折行挤促。优化后改为 顶部 2px 状态色冠 + 顶行徽标/中文结论/核心倒计时 + 全宽主标题与正文，字宽提升 22%。

4. 三页签对齐 V2 分段控件.cr-tabs / .cr-tab

现状为旧式左对齐底划线页签；优化后对齐 V2 标准三等分槽位容器（--bg2 槽底 + --ac-bg 鼠尾草绿选中态）。

5. 参数收口 + 消灭 7 格奇数黑洞.cr-config-card / .cr-metrics

将需求、用量档位与订阅到期日收纳进紧凑参数卡，说明提炼至标题行右侧；7 项指标采用 2×3 对称网格 + 第 7 项跨双列横排（grid-column: 1 / -1），彻底消灭右下角空白黑洞，行动指引在首屏直接可见。

6. 计划 KPI 三格带 + 时间轴同色锚点 + 滑块吸附.cr-plan-kpis / .cr-timeline

提炼「省卡策略 / 严格不断档 / 到期缺口」三格大数字；时间轴增加已过进度段与同色图例圆点（解决圆点在 21% 而文字居中在 50% 的错位）；未手动调速时滑块自动吸附至实测日均速度附近并提供「恢复实测」入口。

7. 依据页 0→4 卡片步进器.cr-path / .cr-evidence-grid

将原本昏暗的左竖线列表升级为序号方块 + 语义胶囊徽标步进表，当前命中的需求步高亮显示；区分动态触发的告警提示与静态规则说明。

8. 修复详情遮罩底部 10px 漏底瑕疵styles.css .shade

实机验收截图底部均漏出半行背景卡片（.shade 写死 bottom: 43px，而 .foot 实高 33px）。修正为 inset: calc(45px*var(--u)) 0 calc(33px*var(--u)) 严丝合缝贴齐底栏。
