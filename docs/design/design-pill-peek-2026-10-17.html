1. 先说人话

你要的是点一下胶囊、不展开面板，就知道三件事：今天花了多少、谁最紧张、签到领没领。这个需求没问题， 问题出在我把它做成了"胶囊长高、上半截显示两行字"——真机上它看起来既不像胶囊、也不像气泡，像把面板压扁塞进了胶囊。

2. 为什么还是怪（三条，都能复现）

#现象根因
1胶囊从"药丸"变成"被吹起来的豆子" 胶囊圆角是 999px。高 46 时圆角=23（标准药丸）；高 120 时圆角被钳到 60， 宽 164、高 120、四角半径 60 → 接近"圆角方块"。这是几何，不是配色
2像"缩小版面板"，两个视觉主体抢注意力 上半是信息、中间一条分割线、下半还是原来的胶囊脸 —— 一个控件里出现了两个主体
3同一颗胶囊两次点开，高度可能不一样；贴边时还会"跳一下" 预留高度是按内容实测的（120 / 151 都出现过）；外加层会触发 clampToMonitor 挪位置
真机测量（125% 缩放，v0.1.36） 胶囊常态 164×67（内容区 164×46）→ 速览时 164×120，内容 41px、分割线在 64px、胶囊脸在 64~109px。 圆角从 23 变成 60。截图里那个"大圆角方块"就是这么来的。

3. 把需求拆开

  • 三个问题，按"一天里被问到的频率"排:最紧张是谁（最高）> 今日花了多少 > 签到状态。
  • 三个硬约束:① 不打断（不展开面板、不抢焦点）；② 不改变挂件身份——它是一颗胶囊， 不是小面板；③ 数字必须和面板口径一致，取不到就说"——"，不编。
  • 一条隐含约束:胶囊的宽高/形状不该因为"看一眼"而变化。一旦变，它就不再是那件东西了。

这条隐含约束是这次设计的核心。下面五个方向，就是围绕"要不要动形状、动多少"排的。

4. 五个方向（按真实 164×46 做，直接点胶囊试）

A · 原地翻页推荐 · 零几何
4S ¥18.20▲
点击后播三页，每页 1.6 秒，播完自动回原值

做法:形状、宽高、位置全不动，只把胶囊里的文字依次换成 「今日 ¥6.42」→「最紧 4SAPI 9%」→「签到 1/2」→ 回原值。
优点:原理上不可能"怪"；零窗口几何操作；和现有的 8 秒轮播是同一套语言。
代价:一次一条，三条要 4.8 秒；期间原来那个数暂时看不见。

B · 横向加宽一次看全
4S ¥18.20▲
点击后宽度 164 → 260，高度不变

做法:不加高，只加宽到 260，塞一行： 「今日 ¥6.42 · 最紧 4SAPI 9% · 签到 1/2」。仍是药丸（半径=23），只是变长。
优点:一次看全；形状身份不变；胶囊宽度本来就是内容驱动的（132~280 已经会变）。
代价:仍是一次窗口宽度变更（约 1 帧）；贴屏幕右边要朝左长，多屏/贴边需要 clamp； 一行 11.5px 的密排，读起来像状态条，不如翻页从容。

C · 抬升卡片当前做法的修正版
4S ¥18.20▲
今日 ¥6.42
最紧 4SAPI 9%
签到 1/2
圆角 16px 时是"小卡片"；999px 时就是你觉得怪的那个样子

做法:长高到 120，但把圆角从 999 改成 16、隐藏胶囊脸，只留信息 + 底部一条 2px 状态色。
优点:信息最全、和面板同一套排版。
代价:形态身份变了（药丸 → 卡片），用户会问"我刚才那颗胶囊呢"； 高度不定、贴边会挪位置 —— 前两个 bug 都出在这里。

D · 独立提示窗工程面最大
今日 ¥6.42 · 最紧 4SAPI 9% · 签到 1/2
4S ¥18.20▲
主窗口完全不动，另弹一个无边框小窗

做法:单独一个 240×88 的提示窗贴在胶囊上方。
优点:尺寸自由、主窗口零变形。
代价:多一个窗口要管层级/焦点/跟随移动/退出清理；贴边与多屏要自己算锚点。 为了"点一下看三个数"引入第二个窗口，不值。

E · 不做速览最保守
4S ¥18.20▲
单击 → 展开面板（或紧凑条）
点击胶囊 = 展开面板；▲ 与现在一致

做法:撤掉速览，只保留 ▲ 展开。
优点:零新增代码、零风险。
代价:"看一眼"的成本从"点一次"回到"展开面板再关掉"—— 而这正是当初提这个功能的理由。

5. 我的推荐:A（原地翻页）

为什么是 A:这次两次"怪"的共同点都是形状/尺寸变了。A 是唯一在原理上不会怪的方案 —— 胶囊自始至终是那颗胶囊，只是"开口说话"。它和胶囊已有的 8 秒轮播是同一套语言（文字在变、形状不变）， 用户不需要学新东西；实现上不碰任何窗口几何，前面两个 bug 那类风险直接归零。
代价说清楚:一次只显示一条，三条要看 4.8 秒，期间原来那个数暂时看不见。 缓解:① 每页 1.6 秒（够读一行，也不至于等太久）；② 播放中再点一次立即结束、回到原值； ③ 发丝条与状态色不动，视觉上始终是"同一颗胶囊在换字"，不是"换了一个界面"。
备选（如果你更想"一次看全"） 选 B。它同样保住了药丸形状，只是把胶囊拉长一点；代价是宽度的瞬时变化与贴边时的展开方向。 C 不建议（形状身份变了）；D 不建议（为一个速览引入第二个窗口）；E 只在"你其实不需要速览"时选。

6. A 方案的详细规格

6.1 交互

项规格
触发单击（位移 < 4px 且按下时长 < 400ms）。拖动、双击、右键都不触发；贴边竖条形态不响应
序列今日 → 最紧 → 签到 → 回原值。每页 1.6 秒；缺数据的那页自动跳过（例如没启用签到就只播两页）
提前结束播放中单击 = 立即回原值；按 ▲ 展开面板也会立即结束
轮播冲突速览期间暂停胶囊的 8 秒轮播，结束后恢复原来的轮播位置
托盘不跟。托盘是"常驻可信信号"，不该跟着翻页跳字（裁决 4）

6.2 视觉

  • 形状、宽高、位置、圆角、底色、图标、状态点、发丝条：全部不动。只有中间那一行文字在换。
  • 每页格式：今日 ¥6.42 / 最紧 4SAPI 9% / 签到 1/2。 字标（今日/最紧/签到）用 --tx3，数值用 --tx 650 字重； "最紧"的百分比按状态色（绿/黄/红）。
  • 换页动效：旧字 150ms 淡出上移 2px → 新字淡入；prefers-reduced-motion 下直接换字。
  • 播放期间锁宽：开始速览时把宽度定为「当前宽 vs 三条文案各自所需宽」的最大值，全程不动， 播完恢复内容驱动宽度 —— 否则文字一长一短，胶囊宽度会跟着呼吸，又变成"动形状"。
  • 宽度：平时仍是内容驱动（132~280），这是既有行为；只有速览这 4.8 秒是锁定值。

6.3 数据口径（与面板同源）

  • 今日 = 全部金额型渠道的今日消耗之和（与汇总条同一口径；不含订阅摊销以外的估算口径变化）。
  • 最紧 = 与胶囊"自动选最紧张"同一个排序函数；百分比渠道取主窗、金额型取本轮额度；取不到显示 —。
  • 签到 = 已启用渠道的"今日已领 / 总数"；一个都没启用 → 跳过这一页。
  • 只读现有视图里的值，不新增任何请求。

6.4 边界

  • 没有可用渠道 → 「今日 —」+「最紧 —」，签到页跳过。
  • 取数失败（显示的是上次快照）→ 照常显示数值，与胶囊平时一致（胶囊本来就会显示上次快照）。
  • 读屏：不加 aria-live（每 1.6 秒播报一次会吵）；tooltip 里保留完整信息。
  • 开关：显示页加「单击胶囊看速览」，默认开；关掉后单击胶囊无动作。

7. 改动面与风险（给研发，可跳过）

  • 删：peek-open 的窗口长高、--peekh、.pill-peek 绝对定位与气泡 DOM、 PEEK 状态与相关 clampToMonitor 调用（v0.1.36 那套整体退役）。
  • 加：胶囊文字层一个"临时覆盖"状态（不改数据源），1.6 秒翻页定时器、结束回落、 播放中暂停轮播；单击/拖动判定沿用现有 4px / 400ms。
  • 风险：低 —— 无窗口几何操作；唯一要盯的是"速览与 8 秒轮播/托盘重绘"三者别打架。
  • 回归面：胶囊轮播、贴边、形态切换、托盘 tooltip（应始终是原渠道值）。

10. 裁决结果与实施（2026-10-17 回填）

裁决:选 C · 抬升卡片 方向按 C 实施,其余取推荐值:三行信息全显示(缺数据的那行自动不出现)、托盘不跟、开关默认开。
落地要点(与第 6 节规格的差异只有"不再有翻页"):
  • 圆角进 peek-open 时从 999 收到 16(带 180ms 过渡)—— 这是"不怪"的关键;
  • 窗口向下长高(顶边不动);高度按实测三行夹在 56~96;宽度锁在「当前胶囊宽 vs 信息所需宽」的较大值(上限 280);
  • 胶囊脸留在顶部(圆点/图标/当前值/▲ 都在),信息在它下方,中间靠发丝条自然分隔,没有额外分割线;
  • 再点一次立即收回;4.5 秒自动收回;切形态时先收回卡片再切(避免半截状态);
  • 显示页新增「单击胶囊看速览」开关,默认开。
真机(125% 缩放)实测:67→123 高、圆角 999→16、胶囊 142×46 不变、向下长高、4.5 秒收回;零异常。
