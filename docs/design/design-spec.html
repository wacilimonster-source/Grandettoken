3 · 四形态尺寸 按 0.4 倍比例绘制

所有形态固定尺寸、不可拖拽改变大小。真正挡住拖拽的不是 min/max 钳位,而是窗口样式里没有 WS_THICKFRAME 和 WS_MAXIMIZEBOX —— Windows 对程序化 SetWindowPos 不套用 tracking 约束。

4 · 状态色阈值

绿 · 剩余 > 40%
黄 · 15–40%
红 · < 15%
默认 --warn 40% / --crit 15%,可在管理页「阈值」调整(黄 50/40/30/20 · 红 20/15/10/5) 灰 = 未配置密钥 或 取数失败 —— 两种语义目前共用一个灰点,建议拆分
配额型渠道的比例取「本月窗」剩余,不取最紧窗口 —— 订阅按自然月结,5 小时 / 本周的波动不该左右整行观感。
充值型(DeepSeek / Hapi)没有分母,不画进度条、不参与百分比排序,状态恒为绿。

5 · 信息架构 展示面与配置面互不重叠

展示面 body 默认

  • 标题栏 —— 计数 / 刷新 / 设置 / 置顶 / 切换紧凑条 / 隐藏
  • 汇总条 —— 今日 / 本周 / 本月消耗合计(仅金额型)
  • 渠道行 —— 图标 + 名称 + 状态点 + 主数值 + 口径 + 进度条 + 三格消耗
  • 行展开 —— 区间切换 / 明细 KV / 迷你柱图 / 数据来源说明
  • 底栏 —— 状态汇总 / 设置与管理 / 退出

配置面 body.view-manage

  • 密钥 —— 每渠道状态 / 删除 / 输入 / 保存
  • 额度申请 —— 开关 + 单次额度 / 最短间隔 / 上次申请日期
  • 刷新 —— 展开态 / 折叠态 / 失败退避间隔
  • 渠道顺序 —— ▲▼ 调自定义排序
  • 胶囊显示 —— 多选芯片
  • 显示 / 阈值 / 启动
约束:展示区不放任何设置项。行详情里只留一句「密钥、刷新与阈值在『设置与管理』里配置」的入口链接。 这条来自一次真实的设计失败 —— 改版前设置是下压面板、密钥藏在每个渠道的展开区里,两处分散且"管理密钥"入口名不副实。

6 · 优化看板 28 条,按影响面 × 实施成本分级

P0 · 优先做 11 条
A4文字对比度达标
--tx3 实测 3.54:1,低于 AA 的 4.5:1;提到 #7b8499 → 4.91:1
成本 一行改动 · 全部小字受益
A7滚动条样式覆盖 .rbody
行详情滚动时出现系统浅色滚动条,深色卡片里非常突兀
成本 一行改动
A3状态点语义分层
灰点同时表示"未配置"和"取数失败",语义完全不同
成本 低 · 兼色盲可用性
A11焦点态与开关语义
.sw 是 div,键盘完全不可达;所有控件都没有 :focus-visible
成本 低 · 可达性合规
B6刷新按钮真实进度反馈
动画 720ms 就结束,但取数是 4 个渠道串行、单渠道超时 20s;用户会重复点击
成本 中低
B7汇总条恢复环比
原型稿有 ↑12% / ↓4%,实现时去掉了;看不出"今天比昨天多花还是少花"
成本 中 · 需历史同期数据
B8排序入口前置到展示区
排序是高频操作,却藏在管理页 select 里,要 3 步才能改
成本 低
B9+N 徽标可交互
紧凑条藏起来的渠道只有纯文字 +N,点了没反应 —— 信息可见但不可达
成本 低
B12原生对话框换自绘
confirm / alert 与界面风格脱节,alert 还会阻塞;在无边框透明窗口上尤其突兀
成本 中低
B13窗口位置持久化
形态持久化了,位置没有;每次开机都要重新摆位置 —— 常驻挂件的基本预期
成本 中
B3吸附展开态加关闭入口
收回只能靠鼠标移出 1 秒;在设置页里操作时不收回 → 会卡在展开态
成本 低
P1 · 显著提升 12 条
A1建立设计令牌层
字号散落 CSS + JS 内联样式;状态色在 JS 常量和 CSS 变量两处,容易走偏
成本 中高 · 但一次投入长期受益
A2浅色主题
白天浅色壁纸下对比过强;窗口已 transparent,只需换 body 底色与描边
成本 中
A5字号阶梯收敛 9 → 5
相邻差 0.5px 不可分辨,却需要记忆规则
成本 中 · 配合 A1
A6恢复卡片外阴影
原型稿有 0 22px 60px -12px #000,实现时因窗口边界裁切丢失;浅色壁纸上卡片浮不起来
成本 中高 · 需留 10px 透明边距并重标尺寸
A8小尺寸图标清晰度
DeepSeek 位图在 14–16px 下重采样,细节糊成一团
成本 中低
A9动效规范统一
进度条 / 行展开 / 刷新各用一套缓动;贴边展开是瞬变,在屏幕边缘"砸"出 380×560
成本 中
B1吸附预览线
吸附功能界面上零提示,新用户不可能发现;阈值 16px 也不可见
成本 中
B2吸附展开分级
鼠标路过 8px 竖条 150ms 就弹出完整面板,无法区分"路过"与"要看"
成本 中 · 悬停预览 + 点击展开
B4胶囊轮播指示点
5 秒切走会打断阅读,但暂停又"看起来像坏了" → 用指示点让"会变"可见,间隔放宽到 8–10s
成本 低
B5点击穿透 / 锁定模式
置顶挂件挡住下层窗口的鼠标操作 —— 桌面挂件最常见的抱怨
成本 中
B10阈值告警行为出口
notify 开关未接线,行内只有颜色变化;不盯着窗口就会错过
成本 中 · 托盘角标 + 一次性呼吸
B15密钥保存成功反馈
后端 key_hint 已实现未接线;用户无法确认存的是哪把 key
成本 低 · 接线即可
B17托盘角标与菜单补全
角标未实现;菜单缺"切换形态"与状态摘要
成本 中

7 · 建议落地顺序

第一轮 · 纯打磨

不改结构,风险极低,用户立刻能感知
  • A4 对比度
  • A7 滚动条
  • B6 刷新反馈
  • B9 +N 可交互
  • B12 换掉 confirm/alert
  • A11 焦点态

第二轮 · 信息价值

让界面回答"该不该充值"而不只是"还剩多少"
  • B7 汇总环比
  • B8 排序前置
  • A3 状态点分层
  • B13 位置持久化

第三轮 · 结构升级

一次投入,长期降低改版成本
  • A1 设计令牌
  • A5 字号收敛
  • A9 动效规范
  • A6 卡片外阴影

第四轮 · 新能力

扩展产品边界
  • B5 点击穿透
  • B2 + B1 吸附分级与预览线
  • B4 轮播指示点
  • A2 浅色主题
  • B10/B17 告警闭环
两个交叉依赖必须一起改:
· A6 卡片外阴影会改变固定尺寸的标定值 —— build/verify-form.js 的 EXPECT 与 win-style.ps1 的断言必须同步更新,否则验证脚本会假失败。
· A2 浅色主题落地前先做 A4 对比度修正 —— 否则浅色下的层级关系要重新推导一遍。
