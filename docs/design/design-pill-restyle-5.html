0 · 现状基线与本次优化的边界baseline

胶囊现状(styles.css 形态 3):状态点 6px → 渠道图标 26px → 数值 14px → ▲ 展开 → 轮播点(底部居中)。 已有动效:数值滚动 A(320ms)、图标淡入 E(200ms)、指示点 M5、跌破红线一次性红晕 M7、告急呼吸 G(默认关)、形态切换淡入 D1、悬停轮播减速 ×3。 窗口宽由 fitPill() 按文字实测自适应(上限 280·u,±6px 防抖)。

五版方案共同遵守的铁律(摘自 styles.css 动效层注释,新动效不得越界):
  • 短:时长 ≤ 320ms(一次性扫光类可到 560ms,先例如 B 微光);曲线 cubic-bezier(.2,.8,.2,1) 快起慢停,永不回弹。
  • 只动有语义的变化:轮播翻页、刷新数值、状态升降级、悬停反馈;不做装饰性循环。
  • 只用 transform + opacity 做位移;颜色/阴影允许过渡(按钮已有先例)。
  • 无常驻循环:唯一例外是 G 呼吸(默认关)。方案 D 的「悬停进度点」是第二个条件循环 —— 仅悬停期间存在,松手即停,见该节裁决点。
  • 透明窗口两条硬约束:① 不用 backdrop-filter(采不到桌面,纯空转);② 任何阴影/光晕外延 ≤ 10px(窗口四周只有 10px 真透明边距,超出会被裁出硬边,代码注释里实测踩过)。
  • prefers-reduced-motion:全局规则已兜底,新动效自动被压平,无需逐条处理。

方案 A ·「凝练」polish — 在现有骨架上把状态读出来成本 低 · 风险 极低

不动布局、不加元素。三处微调:① 数值随状态染色(告急时整个数字变红,而不是只靠 6px 小点 —— 胶囊唯一的大面积像素就是数字本身,让语义长在信息上); ② 悬停浮起 1px + 阴影加深,给「这是一颗可按的东西」的实体感;③ 状态降级到红时,红晕从状态点扩散到整颗胶囊一次性波纹(复用 M7 曲线,仍只播一次)。 失败态数值转灰,与点语义一致。

方案 B ·「光环」aura — 状态变成环境光,剩%常驻成本 中 · 风险 低

状态不再只住在小点上,而是染到整颗胶囊的描边 + 一圈 6px 微光:绿=宽裕、黄=警戒、红=告急、灰=失联。 隔着半米看轮廓就知道要不要管它。底部加一条 2px 发丝进度条常驻显示剩余百分比(与列表行的 bar 同款 500ms 缓动),刷新时你能看见它涨/退。 代价:发丝条与 M5 轮播点抢底部空间 —— 轮播点退役,页序由 tooltip 的「2/3 轮播」承担。

方案 C ·「仪表」gauge — 环形剩余,点退役成本 中 · 风险 中

把渠道图标装进一枚 30px 环形仪表:环的弧长 = 剩余百分比,环色 = 状态色。数字照旧,状态点退役(环接管语义,省出 6px + 一段间距,胶囊反而能收窄 ~10px)。 刷新时弧长伸缩,翻页时环与图标一起 200ms 淡入(现有 icoIn 扩展到环)。这是五版里「仪器感」最强的一版。

方案 D ·「磁带」ticker — 纯动效/交互版,外观零变化成本 中 · 风险 低

外观一个像素都不改,全部预算花在手感:① 轮播翻页从「数值上滚 + 图标单独淡入」升级为整面(图标+数值)方向性滑动 —— 去下一页向左滑、回来向右滑,空间连续; ② 悬停时当前指示点展开成 12px 进度点,填充走完即翻页(与悬停减速 ×3 对齐)—— 悬停才出现的循环,松手即静,不破铁律;③ 悬停整颗微放大 1.02 + 阴影加深,按压 .97。

方案 E ·「双行」duo — 渠道名常显 + 逐位滚动,信息密度最大成本 高 · 风险 中

胶囊长高一档(46 → 58px):第一行渠道名 10.5px + 今日趋势角标(▼$2.10,涨=红/降=绿,沿用汇总条 U8 语义),第二行数值 15.5px。 轮播多渠道时终于知道「现在这颗是谁」,不用悬停猜。数值更新升级为逐位滚动(odometer):只有变了的数字位在列内上滑,「$74.25 → $71.90」你能看见是 7→7、4→1,而不是整串翻面。

推荐组合:1A + B + D 打包为一期 —— A 的数字染色与 B 的状态描边是同一个语义(状态)的两层表达,叠加不冲突; B 的发丝条给出常驻剩%;D 的方向性滑动把轮播手感补齐。三者都不动窗口几何,fitPill 零改动风险。
  • C 作为可替换单件:如果你更喜欢「仪表感」,可用 C 换掉 B 的发丝条(两者都在表达剩%,不必同屏)。

  • 若只选一个:选 B。胶囊存在的理由就是「不打扰但一眼可知」,光环是五版里对这句话回答得最直接的。

落地清单(任选方案都适用)checklist

  • 改动面:样式进 styles.css 动效层之后的新段落(沿用「设计稿落地」注释分节惯例);逻辑只碰 renderPillFace / pillAnim / fitPill,不碰 applyForm 的几何队列与托盘逻辑。
  • 状态源:全部复用 dotCls(c) 与 remainRatio(c),不新增后端字段(E 的趋势除外,需确认昨日快照)。
  • 拖拽安全:胶囊整体是 data-tauri-drag-region="deep",所有新增子元素(环/发丝条/进度点)必须 pointer-events:none,▲ 与既有按钮除外。
  • 阴影预算:任何新 box-shadow 外延 ≤ 10px(窗口透明边距);本稿所有光晕已按 6px 设计。
  • reduced-motion:全局 @media (prefers-reduced-motion) 已兜底,新动画零额外代码。
  • 验收方式:与 2026-09-23 批次相同 —— 设计稿裁决 → 实现 → bug-report 式截图对照验收,四个状态(正常/警戒/告急/失败)+ 翻页 + 刷新各截一张。
