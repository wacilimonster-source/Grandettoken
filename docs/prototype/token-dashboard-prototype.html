交互说明
四级折叠,一路收窄:完全展开 → 紧凑条 → 胶囊 → 吸附边缘。状态记忆,下次启动恢复。
触发:胶囊/边缘标签 单击 展开;面板 失焦 或按 Esc 回退一级;全局快捷键 Alt+T 任意态唤起。
平台行是主体:余额用 19px 大字并直接染上状态色,一屏内视线自然落到最红的那个。行内固定三段消耗(今日/本周/月),不点开也能看趋势。点击行展开明细(单开,自动收起其他)。
顶部三格是全平台消耗合计,属于次要信息,所以压成一条 34px 的窄条;今日/本周带环比箭头。
状态色:绿 >40% · 黄 15–40% · 红 <15% · 灰 = 取数失败/未配置。
取数失败不留白:行降级为灰点 + "重试"按钮,保留上次成功值并标注时间,避免误判为余额归零。
两类渠道分开渲染:金额型(4SAPI / DeepSeek / Hapi)显示人民币余额;配额型(OpenCode Go)接口只给百分比,行内三格换成 5 小时 / 本周 / 本月三个限流窗口的剩余配额,不显示金额也不参与消耗合计。
轮询不花钱:四个都是账务接口,不是推理接口,查余额不消耗 token。所以展开态 1 分钟、折叠态 5 分钟自动刷新,连续失败退避到 15 分钟,系统唤醒和网络恢复时补一次。
币种统一 ¥:各接口标注的 USD 实际结算为人民币,全部按 ¥ 展示并直接求和,不做汇率换算。
有限额才画进度条:充值型(DeepSeek / Hapi)没有分母,进度条会误导,所以直接不画,只显示余额和消耗。
消耗口径:今日按本地零点起算,本周按周一起算。金额型渠道的消耗多数需本地流水推算(接口只给当前余额),展开区会标注数据来源。
排序:默认按剩余百分比升序,快用完的置顶;可切换为按余额、按今日消耗、按自定义顺序。
托盘:图标角标显示最紧张渠道的百分比;右键菜单 = 立即刷新 / 切换形态 / 退出。
密钥:界面明文输入,落盘写 Windows 凭据管理器,永不进 JSON / 数据库 / 日志 / 导出文件。出网请求只发往渠道自身域名,无遥测无云同步。
