  - `二维码与同步码同时生成 :: busy= failed= code= revealed=false statusCode=null`(断言时二维码尚未生成)
  - `点首页签到格:落到签到中心页签且页签可见 :: hidden=false`、
    `签到中心渲染出今日行与日历带 :: …今日进度 3/5…`(断言读到了别的异步块的桩数据)
- 原始失败输出保留于本轮会话记录;CI release run `43563297821` 的同一门禁为绿。
- **初步根因(待复现确认)**:套件由多个并发 async 块组成,共用真实定时器与全局桩。
  Ctrl+2 用例(verify-codex-reset.js? 否,jsdom-smoke.js:663–669)的轮询助手**先等
  form-pill 出现再断言 form-panel**,上一用例(「顶栏胶囊进胶囊」)遗留的迟到 applyForm
  定时器一旦跨块触发,恰好污染本用例;签到中心用例(:689–)等 420ms 固定延时后点击,
  与其它块的 invoke 桩存在跨块数据污染;二维码用例为固定延时后直接断言,无轮询等待。
  与 AGENTS §6.3(只测存在不测时序)、§6.7(并行资源竞争假红)同型,但本轮为**串行**
  仍偶发,说明不是并行度问题而是套件内跨用例定时器/桩污染。

## 五、问题复核与修复

本节为用户反馈后的复核，保留上文原始验收记录。当前安装版仍为 v0.3.48，修复位于工作区源码。

| 问题 | 复核结论 | 处理 |
|---|---|---|
| 1 | 确认测试套件存在异步隔离缺陷 | 初始化完成后再运行断言，形态、签到和二维码/密钥箱组顺序执行，等待实际结果与几何队列收尾 |
| 2 | 原 UIA 回填失败仍受自动化限制；另确认日期编辑会被周期重绘打断 | 顾问时钟、异步绘制和渠道详情刷新统一保护正在编辑的日期，离焦后补算，保存成功及失败回滚继续走原路径 |
| 3 | 实机观察到目标未激活、控件位于滚动区外及索引过期等输入限制，产品缺陷证据不足 | 自动化按激活、观察、单次操作和重新观察执行 |
| 4 | 实机复现重复标签 toast，源码确认异步销毁与同名创建竞态 | 持有原有打开互斥锁，等待旧标签真正释放后创建；有界超时、失败收尾和旧回调会话校验 |
| 5 | 实机确认字号为「大」，字号倍率及屏幕钳制会参与尺寸计算，未确认 DPI 缺陷 | 增加大字号尺寸回归，修正「只改文字大小」的说明为文字与窗口随字号调整 |

### 证据与边界

- 问题 1 的原 `__ASYNC` / `__ASYNC2` / `__ASYNC3` 在声明时就开始执行，外层依次 await 无法消除并发。Ctrl+2 用例等待胶囊后断言面板，顶栏胶囊用例等待面板后断言胶囊，等待条件均与目标冲突。现改为显式串行调用，各组拥有独立执行阶段。修改后全套连续十轮通过，原有能力名单坏样本注入仍能判红。
- 问题 2 新增输入焦点、草稿和节点身份回归。禁用编辑保护的哨兵必须使该回归失败，启用后通过。冒烟夹具现在显式显示详情遮罩，保证真实焦点检查有效。实机坐标点击日期区域后 UIA 焦点仍显示在文档上，原报告的自动化输入限制仍在，安装包的人工回填结果待验收。
- 问题 4 在未主动打开登录窗时直接观察到 `google-cloud-credits` 已存在错误。所用 Tauri runtime 源码中 `destroy()` 派发窗口事件后即返回，应用原实现随后立即 build 同标签。现在最多等待五秒释放标签，超时报可见错误。旧 session 在关闭开始前失效，创建失败标记结束；旧成功回调也校验 nonce，避免隐藏新一轮窗口。核心测试覆盖延迟释放、始终占用超时和已释放三种情况。
- 问题 5 的源码尺寸链路为 `FS_U` → `panelContentSize` → `formSize` → 显示器尺寸钳制 → `LogicalSize`，使用 Tauri 的 `scaleFactor()` 核对尺寸。该路径未读取 `devicePixelRatio`，原报告据此推断缓存过期缺少证据。当前字号倍率为 1.15，尺寸还受显示器可用空间影响，不能仅用标称尺寸与假设的系统缩放比例反推缺陷。
