# Bug 报告 · Qoder 网页会话串号与「切换账号」（2026-11-09）

> 范围：Qoder 国际版/国内版的余额与逐笔到期明细两条数据链路。
> 结论：**3 个主要 bug，前 2 个已修复并随 v0.3.28 / v0.3.29 发布；第 3 个部分修复、已知限制。**
> 本机数据已修复：余额 98 分正确，到期明细如实显示「未知」，不再错配。

---

## Bug 1：余额与到期明细来自两个账号（数据错配）— 已修复（v0.3.28）

**现状（修复前）**
- 换新账号令牌后，余额立刻变成新账号的 98 分，但「逐笔到期明细」仍显示旧账号的
  18 笔每日 100 分赠送包（合计 1736 分，到期日 11-22 ~ 12-09）。
- 同一条快照里余额 98、`expiring[]` 合计 1736，两个账号的数据混在一起。

**根因**
- 余额走桌面/手动令牌（openapi 网关），到期明细走 qoder.com 网页会话（Cookie），
  两条链路完全独立 —— 换令牌不会动浏览器 Cookie。
- 逐包缓存 `qoder_packs` 只按渠道 id 存，不绑凭据：换号后网页抓取一旦失败，
  旧账号列表会作为"上次成功"继续沿用。
- 界面没有任何"网页会话可能属于旧账号"的提示，错误数据静默展示。

**修复方案**
- 凭据 scope 落库（`qoder_cred_scope_v1:<id>`）；成功取数时发现换号/换令牌，
  记 `qoder_account_changed_at:<id>` 并清空逐包缓存。
- 网页会话登录时刻早于凭据更换时刻 → 判为陈旧（`qoder_web_session_stale`）：
  这一轮不读网页会话、不展示旧明细，文案改为「余额凭据已更换 · 需用当前账号重新登录」。
- 逐包缓存绑定 scope，失败降级只肯用同一本账的列表。

**修复后效果**
- 换号后旧明细立即作废，界面如实显示「未知 / 需重新登录」，绝不拿旧账号记录充数。
- 本机实测：余额 98 + 到期未知，不再出现 1736 分的错配。

## Bug 2：「切换账号」清 Cookie 无效 — 已修复（v0.3.29）

**现状（修复前，v0.3.28）**
- 点「切换账号」日志说"已清该区域 Cookie"，但 Cookies 库里 `qoder_session_cookie`
  的创建时间仍是 11-03 —— 一个都没删掉。
- 登录窗随即被旧会话判成"登录成功"并自动关窗（约 2 秒），用户没机会换号。

**根因**
- `w.cookies()`（无 URI 枚举）在这台机器的 WebView2 上没枚举到 qoder 的会话，
  `matched=0` 又被当成"本来就没有会话"静默放过。

**修复方案**
- 改用 `cookies_for_url`（WorkBuddy 清除登录同一条已跑通的路径），按 `/`、
  `/account/usage`、`/users/sign-in` 三个入口枚举，按 (name, domain, path) 去重。
- 国际版额外清 Google SSO Cookie（`.google.com` / `accounts.google.com`）。
- 校验收紧：罐里有条目却一个都没匹配到目标域 → 直接报错，不再静默；
  诊断日志记录实际清掉的 Cookie 数。

**修复后效果**
- 真机日志出现「已清网页登录 Cookie(31 个)」，计数与库中条目吻合，旧会话 Cookie 确实被删。

## Bug 3：Qoder 登录页自动恢复旧账号 — 部分修复，已知限制

**现状**
- 即使清掉 Cookie（含 Google SSO），Qoder 登录页仍会在约 3 秒内自动恢复上一次
  账号并关窗：网页登录把 token 存在 localStorage 等自己的登录态里，只清浏览器
  Cookie 不够。

**已做**
- v0.3.29 向 Qoder 页面注入一次性清理脚本（清 localStorage / sessionStorage，
  `window.name` 做标记，OAuth 回调不重复清）。真机验证自动登录仍会发生，
  说明平台还有 Cookie/localStorage 之外的登录态来源。

**当前状态与口径**
- 未完成重新登录前，取数侧判旧会话陈旧（Bug 1 的修复兜底），到期明细如实显示
  「未知」，**不会拿旧账号记录充数** —— 数据保证不错配。
- 用户裁决：不需要当前账号的逐笔明细，保持「未知」即可。

**后续方向（未排期）**
- 在登录窗里引导用户"先退出当前账号再登录"（保持窗口不自动关），或
  对比网页会话与桌面凭据的账号 ID，账号不一致时不收窗。

## 本机数据修复（2026-11-09 已完成）

1. 清掉 WebView2 里 `qoder.com` 全部 Cookie；删除 `qoder_web_session_at`。
2. 写入 `qoder_account_changed_at:qoder`，取数侧跳过旧网页会话。
3. 清空 `quota_snapshot_v1:qoder` 里的旧 `expiring[]`。
4. 重启后确认：余额 98 + 到期未知。
   备份：`build/qa/qoder-fix-20261109/`（tokenscope.db.bak / Cookies.bak）。
