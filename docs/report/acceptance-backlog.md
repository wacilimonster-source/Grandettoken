# 跨版本待验收清单

> **用途**:把散落在各版本 PROGRESS 条目里的「待验收」收拢到一处,避免跨版本累积后没人记得。
> **怎么用**:
> - 发版时,把本版新增的待验收项追加到对应分区(一项一行,写清楚需要什么环境);
> - 验收后改「状态」:`通过 YYYY-MM-DD`(附一句结论和证据位置)/ `失败 YYYY-MM-DD → 见 …` /
>   `不再适用(原因)`。**不删行**,失败项修好后另起一行复验;
> - 不写会腐烂的数字(用例数、行数),证据写命令或文档位置;
> - 涉及凭据、同步码、余额的验收:结论里**不写任何原值**,最多写指纹前 8 位。
>
> 首次整理:2026-11-22。来源:`PROGRESS.md` 文末 v0.3.50–v0.3.70 条目、
> `docs/report/progress-archive-2026-11-22.md`、`docs/report/android-sync-remaining-2026-11-02.md`、
> `docs/report/local-gateway-audit-2026-11-19.md` §8.5、`docs/report/test-run-2026-11-18.md`。
> 「首次出现」取最早记录该项的版本;后续版本重复记录的不再单列。
