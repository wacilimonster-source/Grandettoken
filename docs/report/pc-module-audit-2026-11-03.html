二、P1 · 应修(建议本轮处理)

P1摘要第 2 / 3 格键盘不可达

三格摘要里只有「临期积分」是原生 button,「最先到期」和「每日签到」是带 data-act 的 div——鼠标可点,但键盘用户 Tab 不到、回车按不了,「点最先到期打开渠道详情」「点签到进签到中心」两条路径对键盘完全关闭。

证据:cells 标签 = [BUTTON, DIV, DIV],tabIndex = [0, -1, -1];keyActivate 只绑在 #list 与 #manage 上,#sum 无键盘委托。

建议:两格改为原生 <button type="button" class="cell">(与第一格同结构);「最先到期」格保留 data-act="jump",焦点样式沿用现有 :focus-visible。

P1xl 字号下固定窗口高度超出 1080p 屏幕

固定尺寸随字号倍率缩放:单列 / 双列高度在 xl 档为 820 × 1.3 = 1066,加 20px 透明边距后窗口高 1086px,超过 1080p 的可用工作区(约 1040px)。clampToMonitor() 只夹位置不夹尺寸,结果是页脚和最后一张卡被裁出屏幕,且无法缩小(缩放已取消)。

证据:panelContentSize('single' | 'double') @xl = [624,1066] / [1274,1066];win = 1086。同理双列宽 1274+20 在 1280 宽的屏幕也超界。

建议:applyForm 落尺寸前取 monitorInfo() 工作区,把内容高度钳到 min(基准, workH − 40),宽度同理;或 xl 档对固定尺寸使用衰减系数(如 ×1.15)。双列宽度在 1280 屏可回退单列。

三、P2 · 建议优化

P2空台账时「最近变动」整段消失

金额渠道 7 天内没有任何余额变动时,ledgerHtml() 返回空串、消耗柱也无数据,详情里既没有「最近变动」段也没有任何说明——看起来像详情缺了一块,而不是"没有记录"。

证据:changesCache=[] + state=done 时,detailBody 内无 .ledger / .lg-empty / "无记录"文案。

建议:空列表时输出一行「7 天无变动记录」(与消耗柱"零消耗画基线"同一口径),保持详情五段骨架完整。

P2胶囊自动轮播在「余额」排序下会挑最富余的渠道

自动轮播改为"设置排序下的第一个有效渠道"后,排序选「余额高 → 低」时胶囊会一直显示余额最多的渠道——与胶囊"自动显示最紧张的一个"的设计初衷相悖。

证据:balance 排序夹具下 pillV 显示 82.0%(排序第一)而非最紧渠道。

建议:autoPick 使用独立口径:绑定窗比例升序 → 无分母金额型按「余额 / 底线」贴近度 → 积分型按 7 日到期占比;列表顺序仍完全按设置。

P2设置子页残留写死的旧蓝 / 深色交互色

模型页来源芯片、签到筛选、渠道点等选中态仍是写死的深蓝 / 深绿色值,浅色主题下会出现突兀的深色块,也没有跟随鼠尾草主色。

证据:.srcbar-i.on{background:#22304a;color:#cfe0ff}、.ckfilter.on{background:#202b40;color:#c5d9ff}、.cdot.on{background:#16321f} 等(样式表 1059–1154 行一带)。

建议:统一替换为语义令牌 --ac-bg / --ac / --ok,与首页、设置索引同节奏。

P2到期跨点后的口径要等下一轮轮询

相对时间由 60 秒 ticker 原地改文本(不重建页面,这点是对的);但跨过到期时刻后,摘要的「临期合计」、卡片的临期提示仍按旧数据,最长要等一个轮询周期才重算。

建议:ticker 更新 [data-exp-at] 时检测任一时刻从「未来」跨到「已过期」,触发一次 render({});一分钟最多一次,代价可忽略。

P2摘要第一格「N 个 · N 未知」文案偏简

「1 个 · 1 未知」是为了在窄卡片不断行而压缩的写法,首次看会有歧义(什么的"个"?)。tooltip 已带全句,属于可接受,但仍有打磨空间。

建议:备选「1 渠道 · 1 未知」;或把"未知"做成一枚小问号徽标,title 展开全句。

  • HomeView.actionCount 前端仅透传不再展示;后端 order 字段同理(保留兼容,不驱动 UI)。

P3测试基建跟进一步

  • verify-resize.js / verify-form.js 等 CDP 脚本基于"可拖动缩放"假设,固定尺寸后已过时,建议改写为"两档固定尺寸 + 禁用 resizable"断言或退役;
  • jsdom 冒烟未覆盖详情弹层交互(打开 / Esc / 焦点圈 / 逐笔展开),本次真机探针可直接固化为冒烟用例;
  • 形态切换断言用 30ms 定时等待几何队列,偶发抖动(本轮复现 1 次,复跑即过),建议改为轮询等待 classList 就绪。

P3可访问性补充

  • 渠道列表容器建议加 role="list" / aria-label="渠道列表",卡片为 listitem;
  • 详情弹层打开时,背景区域可加 aria-hidden="true"(焦点圈已实现,这是读屏层的补强)。

P3吸附竖条(dock)待人工复测

固定尺寸重构后,dock 的「拖到边缘 → 竖条 → 展开」链路未做真机拖拽验证(需要真实把窗口拖到屏幕边缘)。展开尺寸已改为读 formSize() 的固定值,逻辑上应正确,建议日常使用中顺带确认一次。
