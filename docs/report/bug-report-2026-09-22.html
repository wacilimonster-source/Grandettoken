一、P1 缺陷

P1-1隐藏渠道仍在每轮读本机登录凭据(违背裁决)

app/core/src/fetch.rs:630-631

症状:并发取数闭包里 credentials(def) 在 hidden 判定之前执行 —— 被隐藏的 Trae/WorkBuddy/Codex 每轮仍明文读 storage.json/auth.json、跑 AES 解密、查凭据管理器。

后果:直接违背 v0.1.7 裁决「隐藏 = 停止取数、不读本机登录凭据」和设置页文案承诺;还白做 7 次阻塞 IO。

修法:hidden 检查提到 credentials() 之前;隐藏分支的 has_key 只对 Keyring 型查 secrets::get,App 型直接 false。

P1-2传输/解析失败回落 Amount 型,百分比渠道被渲染成金额卡

app/core/src/fetch.rs:291-297, 305-311

症状:连不上/响应非 JSON 时返回 FetchResult{ valid:false, ..Default },kind 落成默认 Amount、unit 空。

后果:首次取数就失败(无缓存兜底)的 Codex/OpenCode 卡片显示「今日/本周/本月消耗」金额块,管理页给它开出「申请制额度 ¥」配置 —— 对百分比渠道配人民币额度。

修法:这两个分支用 def.default_kind 与对应 unit。

P1-3「跳过此版本」会被下一次任意保存操作抹掉

app/src-tauri/src/lib.rs:68 + app/src/app.js:2066

症状:skip_update_version 只写 Rust 侧 DB;前端内存 CFG.skippedVersion 仍是旧值(null)。此后任何一次 set_config(形态切换 remember=true 每次都发)整份覆盖落库。

后果:用户点了「跳过此版本」,下一次切形态/改设置 → 跳过记录被擦 → ≤10 分钟后同一版本重新弹更新提示,像失忆。

修法:set_config 对 skipped_version/last_check_at 做「入参 None 保留现值」合并;或前端 skip 成功后同步本地 CFG。

P1-4渠道全部隐藏后,托盘数字与胶囊宽停在旧值

app/src/app.js:879-888

症状:renderPillFace() 的「无可显示渠道」分支调完 pillAnim 就 return,绕过末尾的 fitPill() + drawTrayIcon()。

后果:把渠道全隐藏后,托盘仍画着旧渠道的余额数和状态色(挂件缩到托盘后这是用户唯一可见的信息面),胶囊宽/tooltip 也不再跟随。

修法:该分支 return 前补 fitPill(); drawTrayIcon()。

P1-5底栏「有新版本」点开的是空白页签,更新卡片藏在「关于」里

app/src/app.js:2029-2031 + index.html:151(updCard 在 data-p="about")

症状:点击只 openManage() + scrollIntoView,不切页签;管理页默认落在「渠道」页,about 面板 display:none,scrollIntoView 对不可见元素是空操作。

后果:用户点「有新版本 x.y.z」看到的是渠道页,像坏链接。

修法:抽出 showTab(name) 公共逻辑,点击时 openManage + showTab("about")。

P1-6改预警阈值后整页颜色不刷新,最长 30 分钟「不生效」

app/src/app.js:1746

症状:bindSelect 只有 key==="sort" 触发 render();warnPercent/critPercent 改完只落库。

后果:行色、状态点、进度条、胶囊、托盘数字全按旧阈值显示;折叠态轮询 30 分钟一次,用户以为设置没生效。

修法:重渲染白名单加这两个 key。

P1-7吸附态竖条:拖动不更新锚点 y,展开不按实际高度夹边界

app/src/app.js:1334(唯一赋值点)、1351/1361(用 DOCK.y 展开/收起)

症状:吸附后沿边缘上下拖动不会写回 DOCK.y;展开用的是收起态 64px 高夹过的 y。

后果:①下次 hover 展开/移出收起会把竖条瞬移回旧 y,像控件失灵;②竖条停在屏幕下半部时展开成 560px 面板,大半跑出屏幕外,看起来像挂件消失。

修法:settle 判定在 DOCK.on 时刷新 DOCK.y;展开时按 formSize 实际高度重新夹 y。

P1-8轮询自动变宽可能「自己吸附到边缘」

app/src/app.js:1240-1266(applyFormInner 几何 6 连发无 markSelfMove)

症状:fitPill/fitCompact 引起的自动 setSize 走 applyForm,但只有末尾 clampToMonitor 调了 markSelfMove;Windows 上尺寸变化会派生 moved 事件 → scheduleSettleCheck 按位置判贴边。

后果:开着「拖到边缘自动吸附」时,胶囊数值变宽恰好贴到屏幕边缘 → 没人拖动它自己吸附成 8px 竖条。

修法:几何操作前统一 markSelfMove(),或 settle 判定加「距上次真实用户拖动」闸门。

二、P2 缺陷(边界 / 一致性)

修法:统一「任一窗 rate-limited 或 limit_reached」。

P2-4Trae 余额计入已过期仍有剩余的包(待复核)

症状:remaining 累加不筛 expire_time > now,而 expiring 表排除了已过期 → 卡片余额可能比官方口径大,两行数字互相对不上。是否真有「过期但 left>0」的包取决于 API 行为,建议实测一次。

P2-5WorkBuddy 多切片周期包只算第一期(待复核)

app/core/src/providers.rs:509-518

P2-6到期时间字段无单位判据,单位一变就显示 1970/公元 5.8 万年

app/core/src/providers.rs:570-582(DeductionEndTime 盲除 1000)、648-654(codex reset_at 不判毫秒);ExpiredTime 只认字符串、数字被跳过

P2-8num() 接受 "NaN"/"inf" 字符串,NaN 可穿过 round 进序列化污染求和

app/core/src/providers.rs:87-93

修法:加 is_finite() 过滤。

P2-9local_date_start 在 DST 时区 .single() 返回 None 时兜成「现在」,今日/本周窗口失真

app/core/src/fetch.rs:220-226

P2-10失联降级后「已限流」徽标一直挂着(喊的是无法再确认的事实)

app/core/src/config.rs:131-136(且 fetch_all 每轮重新 load)

app/core/src/secrets.rs:24-26
