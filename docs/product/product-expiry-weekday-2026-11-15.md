# 积分到期日期补星期

2026-11-15，按用户要求先确定显示方案，再开发。

## 显示规则

保留现有月日日期，在其后补充本地日历中的时间提示。优先按本地自然日显示「今天」「明天」「后天」。其余日期按周一开始的自然周显示「本周三」「下周三」或「周三」。跨年日期补充年份。

以本地 2026-11-15 周日为基准，示例如下。

| 到期日期 | 渠道卡文案 |
| --- | --- |
| 2026-11-15 | 11-15 今天 |
| 2026-11-16 | 11-16 明天 |
| 2026-11-17 | 11-17 后天 |
| 2026-11-18 | 11-18 下周三 |
| 2026-11-19 | 11-19 下周四 |
| 2026-12-09 | 12-09 周三 |
| 2027-01-02 | 2027-1-02 周六 |

「下周」采用自然周归属。界面日期和星期均使用当前系统本地时区，到账记录的北京日、渠道自己的时间口径各自按既有规则呈现。

## 周额度下次重置日期

用户的「周下次重启日期」按周额度下次重置日期处理。Codex 使用 weekly / 本周窗口的 resetsAt，Antigravity 使用 gemini-weekly 的 resetsAt。

缩略卡在口径标签下增加一行小字，例如上行「本周剩余」、下行「11-20 下周五重置」。两行共用原有 26px 的数值行高度，右侧大数字继续右对齐。底部按既有顺序承载重置卡、5 小时额度和短窗恢复信息。

单列与双列渠道卡在状态轨右侧增加「周重置 11-20 下周五」，与现有短窗倒计时并列。完整年月日、星期和重置时刻放在该日期节点的辅助提示中。

周窗口缺失或时间无效时显示「周重置未知」，到达上报时间后显示「周重置待刷新」。日期随现有分钟 ticker 更新，周重置与积分到期共用「今天 / 明天 / 后天 / 本周X / 下周X / 周X」的日历规则。

## 覆盖与排版

缩略卡右下角和单列、双列渠道卡状态轨的最近一笔积分到期日期使用同一个格式化入口。日期保持单行，缩略卡继续使用两端对齐，长日期可以压缩左侧说明的可用宽度。完整到期日期、年份、星期和时刻由日期节点的悬停提示提供。

日期缺失或无效时显示「日期未知」。渠道无已知逐笔到期信息时沿用现有未知状态。最近一笔选择继续仅包含尚未到期且金额为正的记录，到期后通过既有到期检查切换至下一笔或未知状态。

## 时效与边界

显示随已有分钟 ticker 重算，跨过本地午夜、周日到周一或系统时区偏移变化时重画一次。重画复用既有节点更新，保持卡片位置与焦点。

周归属以本地年月日映射的日序判断，避免夏令时的日长差异。跨月、跨年及闰日按实际日历计算。跨日时根据当前日期重算「今天 / 明天 / 后天 / 本周 / 下周」提示，完整辅助提示同步更新。

## 验证

使用固定时钟覆盖同周、下周、更远日期、周日到周一、跨月、跨年、闰日、未知日期和时区边界。检查跨日更新后的可见文案、辅助提示和焦点。浏览器验证三档字号、深浅主题、14 渠道首屏、长日期与金额，并验证星期新增后左右字段的实际几何边界。
