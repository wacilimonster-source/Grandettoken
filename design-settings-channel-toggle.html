二、设计规则(含边界)

  • 语义:「显示」是展示 + 取数双层开关 —— 隐藏即不请求该渠道接口(WorkBuddy/Trae 也不再读本机登录文件),比单纯藏 UI 更省、也更符合"我不想看它"的意图;
  • 默认值:全部显示。老用户升级后零变化,想收掉谁点谁;
  • 入口唯一:开关只放在「渠道管理」一节(原「渠道顺序」升级合并,不新增顶层分区);密钥区不重复放开关,只加「已隐藏」灰标,避免两处状态打架 —— 与置顶/吸附的「单一写入口」原则一致;
  • 联动范围:主列表、消耗汇总、胶囊轮播与自动选紧、底栏计数、额度申请行、托盘图标全部跳过隐藏渠道;快照照常落库(重新打开后历史不断档);
  • 边界 · 全部隐藏:主面板显示空态引导「所有渠道已隐藏 → 去设置」,胶囊显示「已隐藏 N 个渠道」灰点,不报故障;
  • 边界 · 排序模式:「自定义顺序」下隐藏项保留原位置(灰显),重新显示后顺序不跳位;
  • 持久化:config 新增 hiddenChannels: string[](serde default 空数组,老配置自动兼容)。
