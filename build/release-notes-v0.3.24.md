# Grandettoken 0.3.24 — 网关代理跟随与界面统一

- 网关按系统代理转发上游请求：每次调用前比对环境变量与 Windows 代理注册表，系统代理或绕过规则变化后自动换用新的连接，未配置或命中绕过规则时直连（暂不支持 PAC）。
- 关闭「使用系统代理」的分组保持完全直连，不受系统代理影响。
- 局域网地址列表只公布私有网段 IPv4（10/8、172.16/12、192.168/16），不再列出 Tailscale/CGNAT（100.64/10）、虚拟网卡等无法从手机直连的地址。
- 网关页排版统一到设置页字号与行距：网关状态与启动/停止按钮并入顶部，连接地址、访问设置、上架分组和模型目录按缩放比例排版，窄窗口下按钮不再被挤压。
