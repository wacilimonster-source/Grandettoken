# Grandettoken 0.3.29 — Qoder「切换账号」真正清掉旧网页会话

- 修复部分机器上点「切换账号」提示已清 Cookie、实际会话原封不动的问题：改用带 URI 的 Cookie 枚举（`cookies_for_url`，与 WorkBuddy 清除登录同一条已跑通的路径），不再依赖无 URI 的 `cookies()`。
- 清除范围：当前区域的 `qoder.com` / `qoder.com.cn` 及其子域；国际版额外清掉登录页会用来免选账号的 Google SSO Cookie。只动挂件自己的 WebView2 profile，不影响系统浏览器和其它渠道的会话。
- 换号时向 Qoder 页面注入一次性清理脚本：Qoder 网页登录会把 token 存在 localStorage，只清 Cookie 会在几秒内被页面用旧 token 重建会话；脚本在页面 JS 之前清一次本地存储，OAuth 回调与二次导航不再重复清。
- 清除后校验：Cookie 罐里有条目却一个都没匹配到目标域时直接报错，不再把「没清掉」说成「已清」；诊断日志会记录实际清掉的 Cookie 数。
- 已知限制：Qoder 登录页仍可能用平台自身的登录态自动恢复上一次账号。如果发生，请在登录窗页面里先退出当前账号，再用要使用的账号登录；退出重新登录前，逐笔到期明细会如实显示「未知」，不会拿旧账号的记录充数。
- 其余行为不变：余额、签到、逐笔到期口径均未改动。
