# Grandettoken 0.3.22 — 网关别名与代理设置

- 网关模型 id 改为「别名/模型」两段式（如 `ss/deepseek-v4.1-flash-1017`），别名全局唯一：另一个密钥用相同别名上架会被拒绝，调用时出现重名会明确报冲突而不是随机挑一个。
- 每条已上架密钥可单独选择是否经系统代理访问上游（默认走系统代理）；上架新密钥时也可勾选。系统未配置代理时可能直连，页面已注明。
- 网关随应用启动按上次保存的设置自动恢复运行；启动失败原因直接显示在网关页。
- 新安装默认开启局域网访问（仍强制网关密钥）；局域网地址可选网卡，选择会记住。
- 已上架密钥的可用模型支持「全选」，勾选状态与保存结果一致。
- 修复「分组设置」展开后被挤成右侧窄列、条目信息被顶到左下角的排版问题。

验证：核心测试 418 项 + 6 项同步夹具，外壳测试 12 项（含代理设置继承与持久化用例），前端冒烟 177/177，CSS 形态门 1022 条，刷新稳定性对比、真机回归（自动启动/鉴权/模型 id/代理与全选控件/排版）全过。
