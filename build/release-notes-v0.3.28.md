# Grandettoken 0.3.28 — Qoder 换账号后不再串用旧网页会话

- Qoder 国际版/国内版换账号或换令牌后，逐笔到期明细与余额自动重新对齐：检测到余额凭据变化时，旧网页会话立即判为陈旧，这一轮不再展示旧账号的积分包，改为提示用当前账号重新登录。
- 渠道卡新增「切换账号」：先只退出该区域的网页登录（清 `qoder.com` / `qoder.com.cn` 的 Cookie），再用新账号登录；WorkBuddy 等其它渠道的会话不受影响。
- 修复旧会话仍有效时点「登录网页版」会被立刻判成登录成功并自动关窗、导致无法换号的问题；现在换号会真正走一次新的网页登录。
- 逐包到期缓存改为与余额凭据绑定，网页抓取失败时只沿用同一本账的列表，旧账号的已到期记录不会在新账号上复活。
- 其余口径不变：网页会话拉不到逐笔数据时仍如实显示「未知」，余额与签到链路不受影响。
