# Grandettoken 0.3.19 — 密钥箱平铺排序与默认密钥保护

- 密钥箱改为平铺列表，不再按平台分组成卡；顶部新增排序：最近更新（默认）、最近创建、平台名称、分组名称，选择会记住。
- 渠道当前密钥（4SAPI / Hapi / OpenCode Go 的默认条目）改为只读：不能改名、换密钥或删除，条目里写明「渠道默认密钥 · 只读，请在渠道管理中修改」；渠道密钥被移除后，条目显示「渠道未配置密钥」并禁用复制与显示。
- 新增「复制端点」：每条密钥可直接复制调用端点；未填写端点时按钮不可用。
- 条目行显示「平台 · 分组」，并区分「创建 / 更新」时间；搜索覆盖平台、分组、账号、地址与尾号。
- 旧版本自动导入的默认条目会自动接管为只读记录，已有数据全部保留。

验证：核心测试 418 项 + 6 项同步夹具，外壳测试 11 项（含默认密钥只读用例），前端冒烟 177/177，CSS 形态门 1008 条，刷新稳定性快照对比与真机回归（设置入口 / 焦点环 / 固定布局 / Qoder / 签到中心 / 密钥箱排序与只读）全过。
