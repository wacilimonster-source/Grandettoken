# Grandettoken 0.3.25 — 高分屏托盘数字清晰化

- 托盘数字按任务栏所在显示器的实际 DPI 绘制（100% / 125% / 150% / 200%），不再固定画 32×32 交给系统缩放，避免高分屏上数字发虚、被二次缩放。
- 数字改用整数像素字形：16px 下也能看清三位数；有余量时换成 5 列圆润字形，`k` / `w` / 小数点 / 负号按各自宽度参与排版。
- 缩写更紧凑：去掉无意义的 `.0`（`5.0` → `5`），十万以上直接取整（`112000` → `11w`，`999999` → `100w`）；完整数值仍在悬停提示里。
- 托盘图标更新改为串行发送并合并中间帧，DPI 变化或快速轮播时不会出现旧尺寸图标后到覆盖新图标；发送失败保留重试。
- 托盘移到另一台显示器或系统缩放变化后自动重画，并每 30 秒校验一次托盘尺寸。
