# Grandettoken 0.3.14 — 全端文案体检与提示语统一

对三个端约 1,000 条用户可见文案做了一轮体检，这一版把发现的问题全部落地：

- **标点统一**：句中一律半角，清理了同步页、确认框、下载链路里的全角混用
- **错误提示收编**：Rust/reqwest 的英文原文不再直接显示 —— 界面给一句可读的中文，原文进诊断日志；更新失败按「签名 / 网络 / 下载」分类提示
- **同步错误码对用户隐藏**：`SYNC_*:` 前缀不再露出，码仍在诊断卡与日志里，报障链路不变
- **签到文案统一**：「已领到 / 平台已签 / 没签成」三态；按钮收敛为「领取 / 重试 / 重新确认 / 去登录」
- **底栏计数对齐**：「N 失联」改为「N 告急」，与行内状态词（正常 / 预警 / 告急）一致
- **危险操作确认统一**：退出同步组、重新生成同步码、断开 GitHub、清空日志等 7 处原生弹窗改为行内确认条
- **剪贴板回执三分类**：普通「已复制」；密钥才带「· 剪贴板对其他程序可见」；诊断报告「可直接粘贴给 AI 排查」
- 通知文案更具体（额度剩百分比 + 绝对额）、托盘「立即刷新」改「刷新」、安装器描述自称统一为「挂件」

Android 0.1.10（versionCode 11）同步发布：

- 小组件积分单位与手机 App、PC 统一为「N 分」
- 同步失败只显示中文消息，不再露出 SYNC_* 错误码
- 更新失败给出中文原因（网络 / 签名 / 清单），不再显示 UPDATE_* 英文码
- 「数据可能已过期」统一为「数据较旧」；应用名统一为 Grandettoken Sync
