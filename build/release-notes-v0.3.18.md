# Grandettoken 0.3.18 — 本地模型网关

- 新增「本地模型网关」：在密钥箱里选中 Hapi / Gemini / 书生端砚的条目上架后，本机提供 OpenAI 兼容的 /v1/models 与 /v1/chat/completions。默认只监听 127.0.0.1；开启局域网访问必须同时启用网关密钥；请求带 Origin（浏览器跨站）一律拒绝。
- 网关密钥首次启动自动生成，保存在 Windows 凭据加密区，可一键复制或重新生成；密钥箱条目更换后，对应上架项自动标记并要求刷新，删除条目不留残余。
- 密钥箱支持同一平台同一分组下保存多个账号（旧版本的同名唯一约束自动移除，已有数据全部保留）；新增 API 地址与官网字段，表单改为平台下拉 + 分组 + 账号 + 网址，搜索覆盖新字段。
- 模型页移除「只看编码/对话」过滤芯片：列表本来就只列「能调的 ∪ 已配置的」，这个芯片只会把已配置的模型藏掉。
- 设置与管理入口在管理页内常驻，页内再点不会把你正在读的子页重置回索引。
- 底栏布局按钮改为动作标签：单列时显示「双列」，双列时显示「单列」，悬停提示当前档位。
- Qoder 增加国内版 qoder-cn 的网页登录入口（设置卡片常驻折叠体外、详情弹层就地给出）；国际版与国内版按渠道隔离 Cookie、会话时间、逐包缓存与诊断，互不串号。
- 首页刷新稳定性：相同数据刷新不再整块重建 DOM——数值原地更新，卡片不位移、无旧值重影或扫光；键盘焦点与节点身份保持，状态切换时行高不再跳动。

验证：核心测试 418 项 + 6 项同步夹具通过（8 项真机用例按设计忽略），外壳测试 10 项（含网关 5 项），前端冒烟 172/172，CSS 形态门 1007 条，刷新稳定性快照前后对比与真机回归（设置入口 / 焦点环 / 固定布局 / 签到中心 / 网关功能）全过。
