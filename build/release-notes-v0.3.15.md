# Grandettoken 0.3.15 — 密钥箱回归修复与 PC 主题统一

PC 端设置页改版后，从「设置索引」进入密钥箱时列表不再加载，看不到条目、也没有「新增」入口。这一版修掉回归，并把密钥箱的界面与交互按 PC 主题重做：

- **修复**：索引入口与旧页签栏统一走 `showTab()`，进入密钥箱 / 签到 / 模型 / 关于时都会触发对应数据加载，不再出现空面板
- **界面**：顶部常驻「搜索 + 新增」；平台分组改为设置页同款卡片，条目按行展示标签、尾号、备注、时间和引用关系
- **主题**：全部改用深石墨 / 暖雾白语义令牌，浅色主题不再残留深蓝底与低对比度文字
- **表单**：与卡片同风格，支持回车保存、Esc 取消（避开中文输入法回车确认候选词）
- **搜索**：支持平台、标签、备注与尾号，带一键清除；保存后被筛选内容挡住时会自动清空筛选并定位到新条目
- **反馈**：保存成功自动滚动并高亮对应条目；空态、读取失败、无搜索结果各有明确下一步
- 安全提示常驻页脚：密钥绑定当前 Windows 账户，复制后剪贴板对其他程序可见

验证：`jsdom-smoke` 162/162、CSS 形态门 946 条规则、`cargo test` 413 项、`cargo check --all-targets`、凭据扫描均通过。
